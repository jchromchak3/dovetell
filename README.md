# dovetell
Dovetell is a lightweight context layer for AI-assisted teams.  It captures decisions, prompts, tradeoffs, and workflow context as work happen and turns that context into docsm, wikis, and audit-ready artifacts as you work.

## The Problem
AI tools move fast.  Context and documentation doesn't.

Teams using AI-assisted workflows lose reasoning behind their work constantly.  Analysis drifts from documentation.  Tribal knowledge evaporates.  The AI gives plausible answers that ignore what an experienced teammate would know.

The fix isn't better prompts.  It's better context infrastructure.

## How it works
1. **Do work** in tools that you alrady use.
2. **Answer lightweight prompts** at natural moments -- seconds not minutes.
3. **Context accumulates** as structured Markdown bulds in the background.
4. **Docs render automatically** as document sites, wikis, and compliance artifacts as a byproduct.

## Who it's for  
- **AI-native teams (phase 1).**  Vibecoders, startup teams, and product groups already living in Markdown, Git, and AI.
- **Regulated industries (phase 2).** Manufacturing, quality, and operations teams who need audit trails and process docs without the documentation tax.
